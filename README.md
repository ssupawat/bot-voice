# Bot Voice

Pick a character, tune the tone, and copy a ready-to-use prompt for your chatbot.

A single-file web app (Thai) built with plain HTML, CSS, and JavaScript — no build step, no dependencies.

**Live site:** https://ssupawat.github.io/bot-voice/

## Usage

Open the site, choose a character, adjust the tone sliders, add a custom topic, then copy the generated prompt and paste it into any chatbot.

## Development

Everything lives in `index.html`. Edit it and push — GitHub Pages deploys from `main` automatically.
